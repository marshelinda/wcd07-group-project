# 🌐 Website Portal Kabupaten Bone

Website portal resmi **Pemerintah Kabupaten Bone**, Sulawesi Selatan, Indonesia. Portal ini dirancang untuk memberikan akses informasi publik terkini, berita daerah, dan layanan publik penting bagi **warga**, **pelaku usaha**, dan **pencari kerja**.

---

## 🎯 Fitur Utama

### 🔍 Navigasi Responsif

* Bilah navigasi (**Navbar**) adaptif untuk berbagai ukuran layar.
* Perubahan warna latar belakang saat pengguna melakukan scroll.

### 🧭 Scroll Halus

* Navigasi antar bagian halaman (**Beranda, Profil, Berita, Layanan**) dengan efek scroll yang mulus dan nyaman.

### 🖼️ Carousel Latar Belakang Dinamis

* Bagian **Hero Section** dilengkapi carousel gambar otomatis yang menarik di latar belakang.

### 🏞️ Informasi Profil Daerah

* Menampilkan statistik demografi, luas wilayah, jumlah penduduk, serta **Visi dan Misi** Kabupaten Bone.

### 📰 Berita Terkini

* Menampilkan **update berita** terbaru yang bersumber dari pemerintah daerah.

### 🛡️ Layanan Publik Terpopuler

* Daftar layanan yang dikategorikan menjadi:

  * ✅ **Warga**: Pajak, beasiswa, aspirasi masyarakat.
  * ✅ **Usaha**: NIB, sertifikasi halal, merek dagang.
  * ✅ **Pencari Kerja**: Lowongan kerja, pelatihan, pengaduan ketenagakerjaan.


### ⚙️ Optimasi Pengalaman Pengguna

* Menggunakan **Local Storage** untuk menandai kunjungan pengguna pada halaman beranda, mendukung caching dan personalisasi di masa mendatang.

### 🎨 Desain Modern

* Dibangun dengan **Tailwind CSS** untuk tampilan yang bersih, minimalis, dan responsif.

### 🛠️ Ikon Intuitif

* Menggunakan **Heroicons** untuk ikon-ikon antarmuka yang jelas dan mudah dikenali.

---

## 🛠️ Stack Teknologi

* ⚛️ React + Typescript
* 🎨 Tailwind CSS
* 🛡️ Heroicons
* 💾 Local Storage
